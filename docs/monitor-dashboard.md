# 感測器監控網頁

監控網頁每 5 秒查詢最近 20 筆感測器事件，顯示事件時間、感測器編號、活動、按鈕與訊號強度。

## 設定與啟動

1. 在 NocoBase 建立唯讀角色，只授予 `sensor_events` 所需欄位的查看權限。
2. 建立使用該角色的 API Key。
3. 在專案根目錄的 `.env` 新增 `MONITOR_NOCOBASE_API_KEY`，其值填入唯讀 API Key。不要將金鑰提交至 Git。
4. 在能使用 Docker Compose 的終端機，於專案根目錄執行：

   `docker compose up -d --build --no-deps monitor`

5. 在同一台電腦的瀏覽器開啟 http://localhost:13004。

## 測試

按下感測器 IO0，確認新事件自動出現在第一列，並檢查 LINE 通知。

## 目前限制

- 網頁預設只開放本機連線。
- 顯示時間是事件寫入 NocoBase 的時間。
- 最近按鈕事件只從最近 20 筆紀錄中尋找。
- 事件內容不能用來判斷設備目前在線或按鈕目前狀態。
- BLE、網路或通知流程可能失敗，目前不保證每筆事件和通知都會送達。
- API Key 到期後，需要更新 `.env` 並重新建立監控容器。
